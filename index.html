المشروع المميّز

Ghost Radar V5.0

أداة فحص شبكات واستطلاع متقدمة وسريعة مبنية بـ Python، تجمع بين البنية المعيارية والتشفير القوي ووضع التخفي.

ghost_radar — python main.py 

                


                

                    

                        

                        

                        

                        

                        
                    

                

            


            

                

                    📡
                    
فحص الشبكة المحلية (ARP)

                    
اكتشاف الأجهزة، عناوين MAC، الشركات المصنّعة، وتخمين نظام التشغيل عبر بصمة TTL مع تنبيه فوري للأجهزة الجديدة.

                

                

                    🔍
                    
استطلاع المواقع (Web Recon)

                    
الموقع الجغرافي، مزود الخدمة، شهادات SSL/TLS، الترويسات الأمنية، سجلات DNS عبر DoH، والنطاقات الفرعية.

                

                

                    🛡️
                    
فحص المنافذ والثغرات

                    
مسح SYN، جلب بصمات الخدمات (Banner Grabbing)، والتحقق التلقائي من الثغرات عبر قاعدة NVD الرسمية.

                

                

                    🔐
                    
خزنة AES-256-GCM

                    
تشفير تلقائي للسجلات والتقارير JSON/HTML مع أداة فك تشفير (Unseal) داخل البرنامج والمتصفح.

                

                

                    👤
                    
وضع الشبح (Ghost Mode)

                    
تغيير توقيت الطلبات وإخفاء اسم العملية محلياً، مع دعم البروكسي و Tor عبر متغيرات البيئة.

                

                

                    🌐
                    
عربي / English / Türkçe

                    
عرض سليم للعربية في التيرمنال من اليمين لليسار مع تبديل فوري بين ثلاث لغات.
